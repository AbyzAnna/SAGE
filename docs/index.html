SAGE

Talk to your schedule.

An AI scheduling assistant that converts natural conversation into a real schedule. Built for students and professionals who'd rather talk than wrestle with calendars.

View on GitHub Quick start

What it does

💬

Conversation → Schedule

Tell SAGE "study calc tomorrow 2-4pm, dentist Thursday at 3, call mom Sunday." It extracts events, times, durations, and priorities automatically.

⚡

Automated planning

SAGE proposes time blocks, balances workload across the week, and flags conflicts so you don't double-book yourself.

🔄

Real-time updates

All your open tabs and devices sync over WebSocket. Add an event in one place and it appears everywhere instantly.

🧘

Reduces stress

Suggests breaks, highlights overloaded days, and groups similar tasks so your week feels manageable instead of crushing.

🎓

Students & professionals

Whether it's lectures, deadlines, and study sprints — or meetings, deep work, and 1:1s — SAGE adapts to your workflow.

🔒

Local & private

The AI runs entirely on your machine via Ollama. Your schedule never leaves your computer. No API keys, no subscriptions, no data harvesting.

How it works

1

Install Ollama

Download from ollama.com, then pull the model:

ollama pull llama3.2
2

Clone & install

git clone https://github.com/AbyzAnna/SAGE.git
cd SAGE
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
3

Run it

python3 backend/main.py

Open http://localhost:8000 and start chatting.

Try saying

  • "Block out 2 hours tomorrow morning for studying calculus."
  • "I have a dentist appointment Thursday at 3pm."
  • "Plan my week — I need 10 hours of project work and a workout every other day."
  • "What's on my schedule Friday?"
  • "Move my 4pm meeting to 5pm."

Built with

FastAPI — Python backend + WebSockets
Ollama + llama3.2 — local LLM, free, 2GB
SQLite — event storage
Vanilla HTML/CSS/JS — no build step, no framework lock-in
