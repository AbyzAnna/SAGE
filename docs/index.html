SAGE

Talk to your schedule.

An AI scheduling assistant that converts natural conversation into a real schedule. Built for students and professionals who'd rather talk than wrestle with calendars.

🚀 Try SAGE now View on GitHub

Runs entirely in your browser. No signup, no API keys, free forever.

What it does

💬

Talk or type

Tell SAGE in plain English — by text, mic, or a hands-free voice call. It parses dates, times, durations, and priorities automatically.

📞

Voice call mode

Tap Call and just talk. SAGE listens, replies out loud, and captures events from your stories in real time — even when you're rambling about your week.

📅

One-click calendar sync

Export to .ics (Google, Apple, Outlook) or push individual events to Google Calendar in two clicks. No OAuth setup required.

🔍

Find free time

Ask "find me 2 hours free this week" and SAGE scans your calendar, suggests open slots, and respects your working hours.

🔔

Reminders + countdowns

Browser notifications fire 5 minutes before every event. A live "Today" widget shows what's next with a real-time countdown.

⌨️

Power-user keyboard

Quick-add per day, inline edit, day/week toggle, search filter, undo, and full keyboard shortcuts (? for the cheat sheet).

🧘

Stress-aware

Highlights overloaded days, surfaces conflicts before you book them, and groups similar tasks so your week feels manageable.

🔒

Local & private

Everything lives in your browser. No accounts, no API keys, no servers tracking you. Self-host the full Python+Ollama version for total air-gap.

✅

Tested end-to-end

19 Playwright tests cover the chat, calendar, voice, edit, search, undo, notifications, and export — they all pass in ~13s.

How it works

1

Install Ollama

Download from ollama.com, then pull the model:

ollama pull llama3.2
2

Clone & install

git clone https://github.com/AbyzAnna/SAGE.git
cd SAGE
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
3

Run it

python3 backend/main.py

Open http://localhost:8000 and start chatting.

Try saying

  • "Block out 2 hours tomorrow morning for studying calculus."
  • "I have a dentist appointment Thursday at 3pm."
  • "Plan my week — I need 10 hours of project work and a workout every other day."
  • "What's on my schedule Friday?"
  • "Move my 4pm meeting to 5pm."

Built with

FastAPI — Python backend + WebSockets
Ollama + llama3.2 — local LLM, free, 2GB
SQLite — event storage
Vanilla HTML/CSS/JS — no build step, no framework lock-in
